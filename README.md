# CLIPSCRIPT

> **Production-Grade Generative AI Video Prompt Scripts & Formulas**  
> Curated, copy-ready prompt recipes for Kling, Wan, Seedance, Veo, MiniMax, and ComfyUI.  
> **Live Site:** [https://clipscript.jsxcreatives.com](https://clipscript.jsxcreatives.com)

---

## Overview

**Clipscript** is a curated prompt engineering engine and recipe library developed by **[JSX Creatives](https://www.jsxcreatives.com)**. It houses **2,123 verified prompt formulas** across **10 specialized studios**, engineered for world-class generative video pipelines.

Each recipe features **copy-ready bracketed replacement hooks** (e.g. `(the character from the reference image)`, `(the product from the reference image)`, `(the environment from the reference image)`), direct sample video downloads (**1,237 preview MP4 clips**), **1,470 keyframe reference images**, and **117 input reference videos** for video-to-video replacement.

## Features

- **Copy-Ready Formulas:** Bracketed reference placeholders ready to paste directly into Seedance, Kling, Wan, Veo, or ComfyUI.
- **Audio Playback:** Single-audio playback muting other videos automatically.
- **Direct Downloads:** Immediate download links for preview clips, keyframe images, and input reference files.
